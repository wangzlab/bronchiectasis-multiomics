These are the steps and corresponding scripts used to perform multi-omic integration analysis for each bronchiectasis subgroup.

1. Obtain links between each microbial enzyme (KO) and MetaCyc compounds.
Script: 1_ko2cmpd.pl
Input: metacyc_reactions.txt (provided upon request), compounds.tab (provided upon request), ko2ec.txt
Output: ko2cmpd.txt

2. Obtain links between each microbial enzyme (KO) and metabolites.
Script: 2_ko2metabo.pl
Input: cmpd2metabo.txt, ko2cmpd.txt
Output: ko2metabo.txt

3. Obtain biological links between metatranscriptomic KEGG modules and metabolomic WGCNA modules.
Script: 3_get_metat_metab_link.pl
Input: metag_ko.txt, KEGG_modules.tab, metab_module_assign.txt, metab_module_description.txt, ko2metabo.txt, KEGG_modules.tab, KEGG_cmpd2module.txt, ko_description.txt, metabolite_description.txt, currency_cmpd.txt
Output: metat_metab_link.txt

4. Obtain biological links between metabolomic WGCNA modules and host transcriptomic pathways.
Script: 3_get_metab_hostt_link.pl
Input: metabolite_description.txt, metabo2stitch.txt, bronchiectasis_stitch.txt, metab_module_assign.txt, metab_hostt_associations.txt
Output: metab_hostt_link.txt

5. Integrate biological links between metatranscriptomic, metabolomic, and host transcriptomic modules.
Script: 5_integrate.pl
Input: metat_metab_link.txt, host_pathway_description.txt, metab_hostt_link.txt, metabolite_description.txt
Output: metat_metab_hostt_link.txt

6. Conduct Leave-one-species-out (LOSO) analysis to generate gene depth by excluding each species one at a time.
Script: 6_LOSO.pl
Input: bacterial_species_code.txt, ko_noeukaryotes.txt, all_gene_depth.txt
Output: all_gene_depth_$sp.txt (excluding each species)

7. Random forest prediction of multi-omic links to BSI within each subgroup.
Script: 7_rf_BSI.r
Input: prediction_metab.txt, prediction_metat.txt
Output: rf_BSI.csv
